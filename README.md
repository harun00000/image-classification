# Классификация изображений с помощью CNN

Проект по классификации фотографий природных и городских сцен с помощью свёрточной нейронной сети (CNN) на PyTorch.

Модель определяет один из шести классов: **buildings, forest, glacier, mountain, sea, street**.

В проекте я исследовал данные, обучил и сравнил несколько вариантов CNN, оценил лучшую модель на тестовой выборке и сделал Streamlit-приложение для классификации собственных фотографий.

**[Попробовать приложение (Streamlit)](https://harun-image-classifir.streamlit.app/)**

## Что реализовано

- **EDA:** распределение классов, размеры изображений, визуализация примеров.
- **CNN с нуля:** три свёрточных блока с ReLU и MaxPooling, затем полносвязные слои.
- **Аугментация:** случайные горизонтальные отражения и повороты изображений.
- **Обучение:** Adam, CrossEntropyLoss, стратифицированное разбиение на train/validation, Early Stopping.
- **Эксперименты с архитектурой:** Batch Normalization, Dropout и Adaptive Average Pooling.
- **Оценка качества:** accuracy, precision, recall, F1-score, confusion matrix и анализ ошибок.
- **Streamlit:** загрузка фотографии, предсказанный класс и вероятности всех шести классов.

## Датасет

[Intel Image Classification — Kaggle](https://www.kaggle.com/datasets/puneet6060/intel-image-classification)

Для обучения и валидации использовано 14 034 изображения с разбиением 80/20 и сохранением долей классов. Отдельная тестовая выборка содержит 3 000 изображений.

Все изображения приводятся к размеру 128×128. Аугментация применяется только к обучающей выборке.

## Результаты

Сравнил три варианта модели:

| Модель | Validation accuracy | Validation loss |
|---|---:|---:|
| SimpleCNN | 76,4% | 0,6400 |
| SimpleCNN + аугментация | **83,4%** | **0,4978** |
| CNN + BatchNorm + Dropout | 82,3% | 0,5012 |

Лучшей оказалась **SimpleCNN с аугментацией** — она получила наименьший validation loss.

При этом третья архитектура с BatchNorm, AdaptiveAvgPool и Dropout оказалась значительно компактнее: **155 782 обучаемых параметра против 2 121 638 у SimpleCNN**, то есть примерно в **13,6 раза меньше**. Несмотря на уменьшение размера модели, её качество осталось близким к лучшему результату.

На независимой тестовой выборке выбранная модель получила:

- **Accuracy:** 82,7%
- **Loss:** 0,4921
- **Количество изображений:** 3 000

Лучше всего модель распознаёт леса. Чаще всего возникают ошибки между ледниками и горами, а также улицами и зданиями.

## Запуск приложения

Для запуска необходим Python 3.12.

```bash
git clone https://github.com/harun00000/image-classification.git
cd image-classification

python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

streamlit run app.py
```

После запуска откройте `http://localhost:8501` и загрузите фотографию в формате JPG, JPEG или PNG.

Приложение использует уже обученную модель и работает на CPU, поэтому повторное обучение и скачивание датасета не требуются.

Для работы с ноутбуками установите дополнительные зависимости:

```bash
pip install -r requirements-notebooks.txt
```

Обучение моделей проводилось в Google Colab на GPU T4.

## Ограничения

Модель обучена только на шести категориях и всегда выбирает одну из них. На фотографиях других объектов предсказания могут быть ошибочными, а высокая вероятность не гарантирует правильный ответ.
